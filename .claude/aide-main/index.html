Setup Instructions
OpenAI Setup:
  1. Go to platform.openai.com/api-keys
  2. Create a new API key
  3. Paste it above
Anthropic Setup:
  1. Go to console.anthropic.com
  2. Create a new API key
  3. Paste it above
Ollama Setup (Free, Local):
  1. Download from ollama.ai
  2. Install and run Ollama
  3. In terminal: ollama pull llama3
  4. No API key needed!

Runs on localhost:11434

LM Studio / Custom Endpoint:
  1. Download from lmstudio.ai
  2. Download a model (e.g., Llama, Mistral)
  3. Go to "Local Server" tab → Start Server
  4. Use endpoint: http://127.0.0.1:1234/v1/chat/completions
  5. No API key needed!
Google Gemini Setup:
  1. Go to aistudio.google.com/apikey
  2. Sign in with your Google account
  3. Create API key (select or create a Google Cloud project)
  4. Paste the API key above

Requires Google Cloud project. Free tier available.

xAI Grok Setup:
  1. Go to console.x.ai
  2. Sign in with your xAI account
  3. Navigate to API Keys section
  4. Create a new API key
  5. Paste the API key above

Business accounts may require approval. Check xAI documentation for access.

OpenRouter Setup:
  1. Go to openrouter.ai/keys
  2. Create account and get API key
  3. Access to many models (GPT-4, Claude, Llama, etc.)
